# The SHELL gene, MPOB, Nature 2013

An interactive isometric figure of a nursery seed-screening bench for oil palm: seedlings are leaf-punched, their SHELL genotype is read, and each is sorted into "tenera, plant" or "dura / pisifera, reject". Three cutaway fruits show dura, tenera and pisifera, and a toggle compares a plantation planted with and without screening.

Credit: Rajinder Singh, Ravigadevi Sambanthamurthi & the MPOB team (Singh et al., Nature 500, 340–344, 2013).

- `shell-gene.html`: the standalone page (open it in a browser)
- `shell-gene-preview.png`: 1200×1200 preview for LinkedIn
- `build.mjs`, `model.mjs`, `live.js`, `shell.css`: the source. `build.mjs` uses the Anatomy kit, so rebuild it from inside the anatomy repo: `node productions/shell-gene/build.mjs`
